## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | StefBank |
| 中文名称 | 车厘子银行存款系统 |
| 文档类型 | UI Design Spec |

| 适配平台 | 手机端 H5 / PWA |

| 核心页面 | 首页、流水页、申请页、我的页 |

---

## 2. UI 总体方向

StefBank 的界面不应做成传统银行 App，也不应过度强调“车厘子”图形元素。整体应更像一个干净、温柔、可信的私人储蓄小系统。

设计关键词：

- 手机端优先
- iOS 风格
- 清爽留白
- 柔和卡片
- 圆角设计
- 轻量金融感
- 情侣感克制表达
- 车厘子元素弱化，仅作为轻微品牌点缀

产品气质：

> 可爱但不幼稚，亲密但不肉麻，像一个只属于两个人的私人小金库。

## 3. 视觉原则

### 3.1 克制使用车厘子元素

“车厘子银行存款系统”本身已经有比较强的名称识别，因此 UI 中不需要大量使用樱桃图形。

建议：

- 首屏标题直接写“车厘子银行存款系统”。
- “StefBank”作为副标题或品牌英文名。
- 车厘子图标只保留在卡片角落、状态点缀等小面积位置。
- 不使用大型 3D 樱桃插画作为视觉中心。
- 不堆叠爱心、粉色、情侣头像等过强装饰。

### 3.2 金额信息必须突出

这是一个存款系统，余额和流水准确性比装饰更重要。

设计上：

- 当前余额字号最大。
- 存入、取出金额使用不同颜色区分。
- 每条流水必须展示交易后余额。
- 申请页必须突出可用余额和申请金额。
- 所有金额都要易读、醒目、对齐清晰。

### 3.3 页面风格统一

所有页面统一使用：

- 奶油白背景
- 樱桃红主色
- 白色卡片
- 柔和浅粉/浅绿辅助色
- 大圆角
- 轻阴影
- 底部 Tab 导航

页面之间保持同一套视觉语言，避免首页很可爱、后台很生硬。

## 7. 首页 UI 设计

### 7.1 页面目标

首页用于快速查看账户状态，核心是让用户一眼看到：

- 当前余额
- 我要存钱
- 我要取钱
- 本月存入
- 本月取出
- 储蓄目标
- 最近流水

### 7.2 页面结构

```text
车厘子银行存款系统
StefBank

当前余额卡片
我要存钱 / 我要取钱

本月存入 / 本月取出

储蓄目标卡片

最近流水卡片

底部 Tab
```

### 7.3 当前余额卡片

卡片内容：

```text
当前余额
¥ 1,500
今日正常营业中
```

设计要求：

- 卡片使用浅粉渐变背景。
- 金额使用大号深红字体。
- 卡片右下角可放一个极小车厘子点缀。
- 不使用大型水果插图。
- 状态前可使用绿色小圆点表示正常。

### 7.4 快捷操作按钮

两个按钮并排：

```text
我要存钱
我要取钱
```

设计：

- “我要存钱”为主按钮，红色渐变底，白色文字。
- “我要取钱”为浅粉底，红色文字。
- 两个按钮大小一致。
- 按钮高度建议 56px。
- 图标使用线性图标，不使用复杂插画。

### 7.5 月度统计卡片

两张小卡片：

```text
本月存入
¥ 2,000
```

```text
本月取出
¥ 1,300
```

设计：

- 存入可用浅粉背景 + 红色金额。
- 取出可用浅绿背景 + 绿色金额。
- 注意这里是“本月取出”统计，不一定必须用红色，因为它是统计卡片，不是警告信息。
- 卡片右侧可使用淡色钱包图标。

### 7.6 储蓄目标卡片

内容：

```text
储蓄目标
旅行基金
¥3,800 / ¥10,000
38%
```

设计：

- 白色卡片。
- 左侧可使用圆形图标，如飞机。
- 下方使用进度条。
- 进度条填充色使用主色红。
- 右侧显示百分比。

### 7.7 最近流水卡片

内容：

```text
最近流水        全部 >

+¥300    存入    2026.03.22
余额 ¥1,600

-¥500    取出    2026.04.05
余额 ¥1,100

+¥2,000  存入    2026.04.18
余额 ¥3,100
```

设计：

- 使用白色卡片。
- 每条记录一行。
- 金额、类型、日期、余额分区明确。
- 不使用复杂表格。
- 存入用绿色，取出用红色。

## 8. 流水页 UI 设计

### 8.1 页面目标

流水页用于替代原来的备忘录记录，要求清晰、可追溯、可信。

页面重点：

- 当前余额
- 记录总数
- 最近更新时间
- 筛选类型
- 交易明细列表

### 8.2 页面结构

```text
车厘子银行存款系统
StefBank

流水总览卡片
筛选 Tab：全部 / 存入 / 取出
年份筛选 / 排序筛选

交易明细卡片

底部 Tab
```

### 8.3 流水总览卡片

内容：

```text
流水总览
当前余额
¥ 1,500
共 14 条记录
最近更新：今天
```

设计：

- 使用浅粉渐变卡片。
- 金额大号展示，但略小于首页余额。
- 信息图标使用线性图标。
- 右下角可以保留极小品牌点缀。

### 8.4 筛选区

第一行筛选：

```text
全部    存入    取出
```

设计：

- 胶囊 Tab。
- 当前选中项使用红色渐变背景。
- 未选中项使用浅粉或白色背景。

第二行筛选：

```text
2026年 v        最近记录 v
```

设计：

- 白色圆角筛选条。
- 左侧年份筛选。
- 右侧排序筛选。
- 图标使用日历或下拉箭头。

### 8.5 交易明细列表

列表字段：

```text
图标
日期
类型
金额
余额
进入详情箭头
```

单条示例：

```text
[↓]  2026.03.22
     存入          +¥300       余额 ¥1,600 >
```

```text
[↑]  2026.02.18
     取出          -¥600       余额 ¥1,300 >
```

设计规则：

- 存入使用绿色向下箭头或入账图标。
- 取出使用红色向上箭头或出账图标。
- 金额居中或靠右突出。
- 余额用浅灰小字。
- 每条之间使用细分割线。
- 点击条目进入流水详情。

### 8.6 空状态

当没有流水时显示：

```text
还没有流水记录
第一笔存款会出现在这里
```

配一个极简线性票据图标即可。

### 9.1 页面目标

申请页用于让储户提交取款申请或存款记录。页面要轻松、清楚，降低沟通成本。

```text
StefBank

申请中心卡片
Tab：取款申请 / 存款记录

填写申请表单

最近申请

底部 Tab
```

### 9.3 顶部申请中心卡片

内容：

```text
申请中心
当前可用余额
¥ 1,500
提交后等待行长审批
```

设计：

- 浅粉渐变卡片。
- 金额大号红色。
- 底部提示用灰色小字。
- 可以使用时钟图标表示等待审批。

### 9.4 申请类型 Tab

两项：

```text
取款申请
存款记录
```

设计：

- 胶囊式 Tab。
- 当前选中项使用主色渐变。
- 未选中项使用浅粉背景。
- 点击切换不同表单。

### 9.5 取款申请表单

字段：

```text
申请金额
用途分类
紧急程度
到账方式
备注说明
提交申请
```

金额输入：

```text
申请金额
¥ 500
```

设计：

- 金额输入框高度较大。
- 金额字体使用红色大号。
- 右侧可放清除按钮。

用途分类：

```text
购物 / 吃饭 / 学习 / 交通 / 应急 / 其他
```

紧急程度：

```text
普通 / 今天要 / 救命啊
```

到账方式：

```text
微信 / 支付宝 / 银行卡
```

备注：

```text
想买衣服，今晚之前需要
```

提交按钮：

```text
提交申请
```

设计：

- 主按钮红色渐变。
- 点击后进入待审批状态。
- 提交成功后可显示 toast：

```text
申请已提交，等待行长审批
```

### 9.6 最近申请

内容示例：

```text

取款申请  ¥500   已完成   2026.06.05 >
```

状态标签：

| 状态 | 颜色 |
|---|---|
| 待审批 | 浅橙底 + 橙色文字 |
| 已完成 | 浅绿底 + 绿色文字 |
| 已驳回 | 浅红底 + 红色文字 |
| 已批准 | 浅蓝/浅粉底 + 主色文字 |

## 10. 我的页 UI 设计

### 10.1 页面目标

“我的”页用于账户身份展示、设置管理、数据导出等操作。

页面语气可以更亲切，但不要太花。

### 10.2 页面结构

```text
车厘子银行存款系统
通知图标

用户信息卡片

设置列表

存款小贴士卡片

退出登录

底部 Tab
```

### 10.3 用户信息卡片

内容示例：

```text
Hi, Stef 😊
欢迎回来，今天也要好好守护我们的小金库哦～

你是本银行的行长        切换账号
```

设计：

- 白色大圆角卡片。
- 左侧头像。
- 中间用户昵称和欢迎语。
- 右侧箭头。
- 底部使用浅粉身份标签。
- “切换账号”为浅粉胶囊按钮。

头像建议：

- 可以使用默认头像。
- 可以使用两人头像。
- 不强制使用情侣插画。
- 如果使用情侣插画，应保持温和、低饱和，不要喧宾夺主。

### 10.4 设置列表

分组列表：

```text
账户与安全
收款账户管理
通知设置

存款目标管理
预算管理
标签管理

数据备份
导出账单
关于我们
```

设计：

- 白色卡片。
- 每行左侧线性图标。
- 中间文字。
- 右侧箭头。
- 分组之间使用细分割线。
- 行高建议 56–64px。

### 10.5 存款小贴士卡片

内容示例：

```text
StefBank 存款小贴士
小金库会因为彼此的信任而越来越满哦～
```

设计：

- 浅粉渐变卡片。
- 右侧可放保险箱小插画。
- 插画不要过大，作为辅助装饰。
- 这张卡片用于增强亲密感和产品记忆点。

### 10.6 退出登录

底部放置白色圆角按钮：

```text
退出登录
```

设计：

- 红色文字。
- 左侧退出图标。
- 不使用大红底，避免过强警告感。
- 点击需要二次确认。

## 12. 页面状态设计

### 12.1 加载状态

页面加载时：

- 卡片使用骨架屏。
- 不显示错误金额。
- 余额未加载前可显示 `--`。

### 12.2 空状态

流水为空：

```text
还没有流水记录
第一笔存款会出现在这里
```

申请为空：

```text
还没有申请记录
需要用钱时可以在这里提交申请
```

目标为空：

```text
还没有储蓄目标
设置一个小目标，让存钱更有动力
```

### 12.3 错误状态

余额不足：

```text
余额不足，暂时不能提交这笔申请
```

金额为空：

```text
请输入申请金额
```

网络错误：

```text
网络有点慢，稍后再试试
```

### 12.4 成功反馈

提交申请成功：

```text
申请已提交，等待行长审批
```

存款成功：

```text
存款记录已提交
```

审批完成：

```text
已完成，本次流水已更新
```

## 13. 交互规则

### 13.1 取款申请

1. 用户填写金额。
2. 选择用途分类。
3. 选择紧急程度。
4. 选择到账方式。
5. 填写备注。
6. 点击提交申请。
7. 系统校验余额是否充足。
8. 成功后进入待审批状态。

### 13.2 申请页 Tab 切换

- 点击“取款申请”显示取款表单。
- 点击“存款记录”显示存款表单。
- Tab 切换不应丢失已填写内容，除非用户主动清空。

### 13.3 流水筛选

- 点击“全部”显示全部流水。
- 点击“存入”只显示 deposit。
- 点击“取出”只显示 withdraw。
- 年份筛选默认当前年份。
- 排序默认最近记录。

### 13.4 底部导航

- 点击底部 Tab 切换一级页面。
- 当前页面 Tab 高亮。
- 页面切换时保持底部导航固定。

## 17. 当前 UI 结论

当前版本采用：

> 中文标题优先 + StefBank 副标题 + 低车厘子元素 + 奶油白背景 + 樱桃红主色 + iOS 圆角卡片。

这个方向比较适合长期使用。它保留了“车厘子银行”的专属感，但不会因为装饰过强而显得幼稚，也更容易让 Codex 实现出稳定统一的移动端界面。
